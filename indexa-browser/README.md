# Indexa Browser

Open-source dark web browser for Windows built on Electron (Chromium). The address bar searches the Indexa index of sites, certificates are checked through the Indexa API, and everyday browser features are built in.

Тёмный браузер для Windows на Electron (Chromium) с собственным поиском Indexa. Лицензия: MIT.

## Возможности

- Поиск Indexa в адресной строке (также Google, DuckDuckGo, Яндекс), подсказки из закладок, истории и Indexa
- Проверка SSL-сертификата через API Indexa: издатель, срок действия, HSTS
- Страница-предупреждение при недействительном сертификате, предупреждение для сайтов по HTTP
- Вкладки (закрепление, перетаскивание, меню), приватное окно, закладки и панель закладок, история
- Загрузки с паузой и отменой, поиск по странице, масштаб, печать, PDF, скриншот, исходный код страницы
- Инструменты разработчика в отдельном окне, контекстное меню, проверка орфографии
- Подсказки при первом запуске, проверка обновлений, необязательная блокировка рекламы

## Сборка

Нужны Node.js 22+ и Windows (или Linux для сборки без вшивания иконки).

```bash
npm ci
npm run dist
```

В приложение по умолчанию зашит общий публичный ключ API Indexa (`pk_…`), он создан для открытого использования, поэтому дополнительных настроек для сборки не нужно. Чтобы использовать свой экземпляр Indexa, задайте переменные окружения `INDEXA_API`, `INDEXA_API_KEY` и `INDEXA_UPDATE_URL`: скрипт `scripts/make-config.js` запишет их в `renderer/config.js` (этот файл создаётся при сборке и не хранится в репозитории). Для запуска без сборки: `npm start`.

Готовые файлы: `dist/IndexaBrowser.exe` (портативный) и `dist/win-unpacked/` (распакованное приложение).

## Политика конфиденциальности

Браузер не собирает персональные данные и не содержит аналитики. История, закладки, настройки и список загрузок хранятся только на вашем компьютере.

На сервер Indexa (`indexa-console.pages.dev`) отправляются:

- текст, который вы вводите в адресной строке для поиска, и запросы на подсказки (если выбран поиск Indexa);
- имя хоста каждого открываемого HTTPS-сайта для проверки сертификата;
- запрос списка проиндексированных сайтов для стартовой страницы.

Раз в сутки браузер запрашивает файл `version.json` для проверки обновлений. Адреса страниц, которые вы открываете, на сервер Indexa не отправляются. Если выбрана другая поисковая система, запросы идут напрямую к ней.
